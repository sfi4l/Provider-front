# Кабинет агента

Рабочий стол агента, который закупает у провайдера цифровые поставки в B2B: коды пополнения, ключи, прямые зачисления.

Это **не** админка склада и **не** публичный сайт API. Сейчас в репозитории только кабинет. Данные — локальный мок.

## Кому кабинет

Владелец агентства заходит, чтобы:

1. увидеть баланс и что уже куплено;
2. быстро взять товар на витрине;
3. забрать коды из заказов;
4. пополнить счёт и сверить движения;
5. пустить сотрудников и подключить API.

## Экраны

- **Главная** — приветствие, доступный баланс, быстрые шаги, топ покупок, последние выдачи.
- **Витрина** — бренды и номиналы. Коды сразу в кабинете.
- **Корзина** — списание с баланса, сводка к оплате.
- **Пополнить** — USDT (TON / TRC20), адрес на депозит с QR и таймером 30 мин.
- **Движения** — все проводки по агентскому счёту.
- **Мои заказы** — выданные коды, повтор покупки.
- **Прямые** — зачисления без получателя «на стороне».
- **Сотрудники** — роли и лимиты.
- **API и ключи** / **Как подключить** — live/sandbox и примеры.
- **Настройки** — организация и уведомления.

## Ощущение

Спокойный серый B2B с мягким синим акцентом и золотой подсветкой стартера. Деньги в **USD**.

```bash
npm install
npm run dev
```
